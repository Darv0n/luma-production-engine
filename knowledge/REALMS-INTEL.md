# Realms (app.lumalabs.ai) — Production Intelligence

Compiled from insider training videos + confidential beta presentation.
Presenter: David Chowodona (Luma)

## What Realms Is

A multiplayer canvas powered by intelligent, multimodal creative agents.
NOT a video generator — it's a full creative workspace where AI agents
collaborate with you to create anything across all media types.

Internal codename: "Realms"
URL: app.lumalabs.ai
Relationship to Dream Machine: "the newest addition to the Dream Machine ecosystem"

## Three Pillars

1. **Multi-Modal** — Images, video, sound effects, text, all in one workspace
2. **Multi-Model** — Ray3, Veo 3.1, Sora 2, Nano Banana, Nano Banana Pro, Seedream, OpenAI 1.5, ElevenLabs
3. **Multi-Player** — Shareable canvas, real-time collaboration, notes, doodles

## The Agent — Core Interface

"The most powerful part of the tool. Lean on the agent for everything."

The Agent:
- Knows every model, when to use each, and best practices
- Writes prompts for you — you just describe what you want in plain English
- Batches work — "generate 12 images of different colored coffee mugs"
- Iterates with feedback — "these don't look like ice cream, no scoop, no fudge"
- Maintains context across conversation
- Creates templates — "summarize what we just did" → reusable process
- Plans multi-shot videos — shot planning, character consistency, sound design
- Answers questions about theory, tools, techniques
- "It knows more than even I do about these tools"

## Two Usage Modes

### Director Mode
- Don't need to know "how the sausage is made"
- Just know a good result when you see it
- Give high-level instructions: "I don't like this because X, try again"
- Judge and jury — the Agent handles execution

### Production Artist Mode
- Control every single aspect of execution
- Specify models, parameters, variations
- Granular prompt engineering through the Agent

## Key Workflows Demonstrated

### Batch Generation
"Generate 12 images of different colored coffee mugs on a table"
→ Agent writes 12 prompts, generates all at once

### Multi-Modal Single Prompt
"Theme: Coffee being poured into a coffee mug. Generate simultaneously: Image, Video, Sound Effects"

### Iterative Refinement (Director Mode)
1. "Create ice cream inspired architecture" → boring results
2. "These do not look like ice cream. No scoop, no fudge. Be more creative." → better
3. "I don't want white background. Make the whole building edible and more realistic." → improving
4. "Keep going in that direction. Push this even further." → great results
5. "Summarize what just happened in this process" → reusable template

### Character Consistency Across Shots
- Agent advises: create separate reference sheet per character
- Use BOTH reference sheet AND original image together (dual reference)
- Label references explicitly: "Use image 1 as character reference, image 2 as background"
- Escalate quality: Seedream first → Nano Banana → Nano Banana Pro

### Multi-Shot Video Production
- Agent helps plan shots and script
- Creates character assets in multiple styles
- Designs shot list
- Generates sound effects
- Maintains character consistency across scenes
- Example: "Witch & Wizard Claymation" — 5 characters, multiple scenes, SFX

### Scale Operations
- "Analyze these ice cream sundaes and create 16 inspired fashion items"
- "Try this with every single image model and give me four versions of each"
- Going from 2 seed assets to 16+ derived products

### Motion Graphics
- Text overlay on video
- Animated logos
- Auto-generated taglines
- "Come up with some motion graphics and a tagline for this logo"

## Pro Tips from Presenter
1. "Lean on the agent" — repeated 10+ times
2. "Treat it as a real creative team under you"
3. "Good in, good out" — more context = better results
4. "Be ready for that interaction, that back and forth"
5. Don't rewrite prompts technically — describe what you want in plain language
6. Select assets on canvas and tell the Agent what to do with them
7. Ask Agent to summarize successful processes into reusable templates
8. Compare models side by side before committing to a direction
9. Start with Seedream for speed, escalate to Nano Banana Pro for quality
